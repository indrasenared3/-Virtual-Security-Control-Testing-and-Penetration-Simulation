# Virtual Security Control Testing and Penetration Simulation

## Project Overview
This repository contains the deliverables for the **Week 3 Task: Virtual Security Control Testing and Penetration Simulation**. The primary objective of this project is to assess and test cybersecurity controls by executing a simulated virtual penetration test across network, application, and access control layers.

## Files Included
*   **Virtual_Security_Control_Testing_Report.docx**: The comprehensive penetration testing report detailing the testing methodology, discovered vulnerabilities, simulated exploitation attempts, risk assessment, and prioritized remediation strategies.

## Methodology
The testing simulation was structured using industry-standard frameworks:
*   **PTES (Penetration Testing Execution Standard):** Guided the overall testing lifecycle from information gathering and threat modeling to exploitation and post-exploitation reporting.
*   **OWASP Top 10:** Utilized to structure the analysis of application-layer vulnerabilities.

## Key Findings
During the simulated assessment, several vulnerabilities were identified and documented:
1.  **Broken Access Control (Insecure Direct Object Reference):** Identified at the application layer, allowing unauthorized privilege escalation.
2.  **Unpatched Service (Remote Code Execution):** A critical network/host layer vulnerability demonstrating the impact of outdated software.
3.  **Misconfigured Cloud Storage:** An access control flaw resulting in unintended information disclosure.

The attached report provides a detailed risk assessment and prioritized recommendations to bolster the security controls of the virtual environment against these vectors.
